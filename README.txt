CASHFLOW HARIAN - WEBSITE + HOME SCREEN

KANDUNGAN
- index.html: aplikasi Cashflow Harian asal
- manifest.webmanifest, sw.js, icon-192.png, icon-512.png: sokongan installable PWA/offline

PENTING TENTANG DATA
Versi asal menyimpan rekod dalam storan pelayar (localStorage) pada peranti/pelayar itu sahaja. Ia TIDAK menyegerakkan rekod secara automatik antara telefon dan laptop. Jangan padam data pelayar atau tukar pelayar sebelum membuat salinan rekod. Untuk sync merentas peranti, perlu tambah pangkalan data dan log masuk.

CARA TERBITKAN LINK PERCUMA (GITHUB PAGES)
1. Buka https://github.com dan daftar/log masuk.
2. Cipta repository baharu bernama cashflow-harian.
3. Muat naik SEMUA fail dalam folder ini ke repository (pastikan index.html berada di root).
4. Pergi Settings > Pages.
5. Di Build and deployment, pilih Deploy from a branch, branch main, folder /(root), kemudian Save.
6. Tunggu proses selesai. GitHub akan beri URL website, biasanya https://USERNAME.github.io/cashflow-harian/.

CARA TAMBAH KE HOME SCREEN iPHONE
1. Buka URL website yang sudah diterbitkan menggunakan Safari.
2. Tekan butang Share (ikon kotak dengan anak panah ke atas).
3. Pilih Add to Home Screen.
4. Tukar nama jika mahu, kemudian tekan Add.

CARA TAMBAH KE HOME SCREEN ANDROID
1. Buka URL menggunakan Chrome.
2. Tekan menu tiga titik.
3. Pilih Install app atau Add to Home screen.

Website perlu dibuka melalui HTTPS untuk fungsi install dan offline.
